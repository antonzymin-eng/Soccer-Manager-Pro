# Positional Rotations Specification #25 — Section 7: Future Extensions and Deferrals

**Created:** July 8, 2026
**Last Updated:** July 8, 2026 (v0.1)
**Version:** 0.1
**Status:** IN REVIEW

---

## 7.1 Cyclic (3+) rotations

Real positional play includes three-agent carousels. Excluded (KD-2/§3.3 partner lock forbids
emergence via chaining); a future version needs its own trigger model and a much harder
ShapeAnalyzer contract. No hook written.

## 7.2 Choreographed rotations

This spec *ratifies* organic exchanges (KD-3). Instructing rotations proactively ("the 8 attacks
when the 10 drops") is a role/duty-driven behaviour belonging to #21's role model + #12 anchor
logic — a different mechanism, not a bigger trigger radius. Deferred.

## 7.3 Out-of-possession rotations

Defensive cover swaps are #14's territory (its cover/balance logic already reassigns
*responsibilities* without touching slots). Any OOP slot swap must renegotiate the #12/#14
boundary first. Deferred with no hook.

## 7.4 Rotation-aware role weighting

Post-rotation, an agent occupies a slot whose `RoleId` differs from its `PlayerRole` expectations;
a utility-weight blend during rotations is a #8/#21 balance-pass idea once base behaviour is
validated. Deferred.

## 7.5 Per-pair tactic configuration

KD-1 chose the static table (design-note open question 3). Making eligibility tactic-configurable
is the recorded larger-surface alternative if the balance pass demands it.
