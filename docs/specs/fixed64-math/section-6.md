# Fixed64 Math Library Specification #9 — Section 6: Golden Test Vectors

## 6.1 Vector Schema
- Required fields: `schema_version`, `operation`, `inputs`, `rounding_mode`, `expected_raw`, `expected_flags`.

## 6.2 Baseline Coverage
- Baseline vectors MUST cover normal arithmetic and comparison paths across positive, negative, and zero values.

## 6.3 Boundary Coverage
- Vector corpus MUST include min/max, overflow edges, sign transitions, and divide-by-zero outcomes.

## 6.4 Utility Coverage
- `sqrt`, trig, and interpolation vectors MUST include envelope assertions and representative domain boundaries.

## 6.5 Conversion Coverage
- Include int/float/fixed conversions for exact, lossy, out-of-range, and unsafe examples.

## 6.6 Provenance Policy
- Vectors MUST be generated by a canonical tool with fixed seed and reproducible command line.

## 6.7 Change Control
- Vector schema and corpus updates MUST be versioned and backward compatibility impact documented.

## 6.8 Version History
- v0.1 (2026-05-01): Initial draft aligned to outline Section 6.
