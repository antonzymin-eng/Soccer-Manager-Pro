# Offline audit definitions

Created November 10, 2026, before the Stage A capture. The independent analyzer
constructs each window from the complete callback journal: first later tackle or
censor event wins by source order, otherwise the fixed endpoint/capture boundary.
It compares the resulting prefix, endpoint and every recovery flag to the collector,
and reconciles the replayed ownership chain with every trajectory owner sample.

For the source hypotheses, annotate the **first** same-frame original-carrier
acquisition: an explicit later same-frame LoosePickup marker for that carrier is
`passive-pickup`; otherwise an earlier same-frame FirstTouch marker is `first-touch`;
otherwise retain `ownership-seam-only`. Match markers only between the adjacent ownership edges around that first acquisition. This is a descriptive path annotation, not
an extra recovery or a causal football-success metric. Initial planar rest means
both recorded velocity components equal zero exactly; no fitted speed threshold.
No core metric, window or censor definition changes from the design note.
